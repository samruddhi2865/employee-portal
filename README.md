# Employee Portal (HTML & CSS)

This project is a simple **Employee Portal UI** created using **only HTML and CSS**.

## Purpose
- To learn and practice HTML structure
- To understand CSS styling and layouts
- Beginner-friendly frontend project

## Technologies Used
- HTML5
- CSS3

## Features
- Static UI design
- Clean layout
- Basic styling and responsiveness

## Note
This project does not include backend functionality or JavaScript.  
It is created purely for learning HTML and CSS.
